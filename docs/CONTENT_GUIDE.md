# দোয়া ও যিকির কনটেন্ট যোগ করার নিয়ম

ফাইল: `app/src/main/assets/dua/duas.json`  (নমুনা: `docs/duas.template.json`)

## প্রতিটি আইটেমের ফিল্ড
| ফিল্ড | বাধ্যতামূলক | বিবরণ |
|---|---|---|
| `id` | হ্যাঁ | অনন্য, ইংরেজি ছোট হাতের অক্ষর ও `-` (যেমন `morning-1`)। পরে বদলাবেন না, ফেভারিট এই id দিয়ে সেভ হয় |
| `title` | হ্যাঁ | `en` ও `bn` শিরোনাম |
| `arabic` | হ্যাঁ | আরবি টেক্সট (যাচাইকৃত উৎস থেকে হারাকাতসহ) |
| `translation` | হ্যাঁ | `en` ও `bn` অনুবাদ |
| `transliteration` | না | উচ্চারণ (`en`/`bn`) |
| `reference` | না | সূত্র (গ্রন্থের নাম, নম্বর) |
| `repeat` | না | কতবার পড়তে হয় (কাউন্টার দেখায়, ১-এর বেশি হলে) |

## যাচাই
- টেক্সট অবশ্যই নির্ভরযোগ্য, প্রকাশিত গ্রন্থ থেকে নিন এবং একজন যোগ্য আলেম/জানা ব্যক্তির দ্বারা মিলিয়ে নিন।
- সূত্র (`reference`) সবসময় লিখুন, যাতে ব্যবহারকারী যাচাই করতে পারেন।
- AI বা অনির্ভরযোগ্য ওয়েবসাইট থেকে কপি করা টেক্সট ব্যবহার করবেন না।

## ফাইল পরীক্ষা
```
python3 tools/validate_duas.py app/src/main/assets/dua/duas.json
```

# আজকের এজেন্ডা (আমল তালিকা)

ফাইল: `app/src/main/assets/agenda/practices.json`  (নমুনা: `docs/practices.template.json`)
নামাজের সময় নিজে থেকেই এজেন্ডায় আসে। এই ফাইলে আপনি অতিরিক্ত আমল যোগ করবেন। কোন আমল কোন দিন করণীয়, সেটা যাচাই করে লিখুন।

| ফিল্ড | বাধ্যতামূলক | বিবরণ |
|---|---|---|
| `id` | হ্যাঁ | অনন্য id |
| `title` | হ্যাঁ | `en` ও `bn` |
| `time` | না | `"HH:mm"` (২৪ ঘণ্টা), না দিলে সময় ছাড়া দেখায় |
| `weekdays` | না | সপ্তাহের দিন: ১=সোমবার ... ৭=রবিবার (শুক্রবার = ৫) |
| `hijriDays` | না | হিজরি মাসের তারিখ, যেমন `[13,14,15]` |
| `hijriMonths` | না | হিজরি মাস ১–১২ |
| `surah` | না | সূরা নম্বর, ট্যাপ করলে ওই সূরা খোলে |

যতগুলো শর্ত দেবেন সবগুলো মিললে আমলটি দেখাবে। কোনো শর্ত না দিলে প্রতিদিন দেখাবে।

পরীক্ষা: `python3 tools/validate_practices.py app/src/main/assets/agenda/practices.json`
